# App Store 발매 계획 — iOS · iPadOS

> 안드로이드(플레이) 발매가 끝난 뒤에 착수한다. 순서: **웹 → 플레이 → 앱스토어**.
> 패드가 필기용이므로 **iPad 가 사실상 본체**이고, iPhone 은 함께 내는 셈이다.

---

## 0. 결론 세 줄

1. **애플은 "웹을 감싼 앱"을 반려한다(4.2 최소 기능).** 우리 앱은 논문·필기·PDF 가
   기기 안에서 실제로 돌아가고 오프라인에서도 열리므로, 그 점을 **심사 노트와
   화면으로** 보여 주면 통과 가능성이 높다.
2. **앱 안에서 파는 구독은 애플 결제(IAP)로만** 해야 한다(3.1.1). 웹 결제는
   브라우저에서 구독하는 사람의 길로만 남긴다 — 앱 안에서 웹 결제로 유도하면 반려된다.
3. **준비물은 돈보다 환경이다.** 맥 + Xcode + Apple Developer Program(연 $99)이
   필요하다. 이 개발 환경(리눅스)에서는 빌드할 수 없다.

## 1. 심사 요건 — 미리 맞춰 둘 것

| 요건 | 지금 상태 | 할 일 |
|---|---|---|
| 개인정보처리방침 URL | 있음 `/privacy` | `site.mjs` 도메인으로 링크 |
| 계정 삭제(앱 안에서 가능) | 있음 — 계정 화면의 '계정 삭제' | 심사 노트에 경로 적기(5.1.1(v)) |
| 최소 기능(4.2) | 기기 안 필기·PDF·오프라인 | 심사 노트 + 첫 화면에서 바로 보이게 |
| 앱 내 구독(IAP) | 없음 | 프리미엄 월 14,900원 · 클라우드 200GB 를 IAP 상품으로 |
| 결제 유도 금지 | — | iOS 앱 안에서 웹 결제 링크·문구 제거 |
| 로그인 없이 둘러보기 | 로그인 없이 대부분 가능 | 심사용 계정 준비(리뷰 계정) |
| 스크린샷 | 플레이용은 있음 | iPhone 6.7"/6.5", iPad 12.9"/13" 규격으로 다시 |
| 앱 이름·부제 | `notesis — 논문 읽는 노트` | App Store 는 부제 30자 별도 |

> 요건은 애플이 수시로 바꾼다. 제출 직전에 App Store 심사 지침(4.2·3.1.1·5.1.1)을
> 다시 확인하고 이 표를 갱신한다.

## 2. 빌드 — 무엇으로 감쌀까

| 방법 | 장점 | 단점 |
|---|---|---|
| **WKWebView 직접** | 통제 쉬움, 의존성 없음 | 파일·펜·오프라인 처리 직접 구현 |
| **Capacitor** | 플러그인(파일·푸시·결제)이 이미 있음 | 의존성 늘어남 |

지금은 **Capacitor 를 권한다.** 웹앱이 이미 PWA 라 `npx cap add ios` 로 시작할 수
있고, 애플 결제·파일 저장 같은 것을 플러그인으로 붙일 수 있다.

```
appstore/ios/            ← 여기에 생긴다 (지금은 비어 있음)
  App/                   Xcode 프로젝트
  App.xcodeproj
```

- 웹 자원은 `play/playstore/scripts/build.mjs` 조립물을 그대로 넣는다(두 벌 관리 금지).
- 번들 ID: `com.notesis.notes` (`site.mjs` 의 `SITE.apple.bundle`)

## 3. 순서

- [ ] 애플 개발자 프로그램 가입(연 $99) — 개인/법인 정보, 세금·은행 정보
- [ ] 맥에서 Xcode + Capacitor 로 껍데기 만들기 → 시뮬레이터에서 열기
- [ ] 도메인 연결(`site.mjs`) — 심사는 실제 서버 주소를 본다
- [ ] IAP 상품 만들기(구독 그룹: 프리미엄 월간) + 서버 검증
      → 서버는 `userSetPlan(uid, 'premium', { until, source: 'apple', orderId })` 하나로 붙는다
- [ ] 계정 삭제·개인정보처리방침 링크 확인
- [ ] TestFlight 로 본인·지인 테스트(심사 전 필수는 아니지만 반려를 줄인다)
- [ ] 심사 노트 작성 — "웹 래퍼가 아니라 기기 안에서 도는 필기 앱"임을 적는다
- [ ] 스크린샷·부제·설명은 `play/playstore/docs/listing.md` 를 애플 규격으로 옮긴다
